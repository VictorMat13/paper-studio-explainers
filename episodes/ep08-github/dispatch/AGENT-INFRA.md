## What is the same as ep07 and what is different

- Same shape: three hook groups (`HA`, `HB`, `HC`), three body groups (`BodyA`, `BodyB`, `BodyC`), group ids by shot id prefix (`HA*` -> HA, `A*` -> BodyA, ...). A variant is (hook letter, body letter): `A B C AB AC BA BC CA CB` and the YT cut of each. **All 18 exist from the first generation**, provisional from the storyboard (a combo's shots = its hook's storyboard shots, then its body's storyboard shots moved so the body starts after the same 12-frame pause; the ep07 tool's `combo_shots` already does this for real timings; make `--provisional` do it too).
- No group-edge blur breaks: the hook hands off into the body's first card (every hook into every body; the hook builders branch on `bodyOf(variant)`). Keep `crossBreak.tsx` and `CrossBreak` for builders who want a break inside their own group.
- Body starts 12 frames after the hook's last word (provisional) and, once real, where the assembler leaves it. Tail holds: `A15x`, `B10x`, `C10x` (40 frames, 3 frames after the last word).
- CTA keyword is **COMMIT** (the YT cut swaps the CTA shot ids `A15a` / `B10a` / `C10a` for "Subscribe to learn" / "more about AI." the way ep07 did for `A11a` / `B09a` / `C09a`; find the CTA shot by its id or by the text starting "Comment", not by the word CRASH).
- Voice files: `staticFile('ptp08/vo/<variant>.wav')` unless `mute` or `provisional`. They do not exist yet; the provisional timeline must render without them.
- Hook overlay text (two lines): "How to use GitHub" / "when you build with AI", from frame 0 until the body's first shot, fading over the last 6 frames.
- Root composition `GithubEp08` (comp id `GithubEp08`, props `{ variant, mute }`), `PadCtx` 0.9, the single `CrtPass`, `VO_PREFIX = "ptp08/vo"`.

## Build

1. Copy `C/src/ptp07/` to `C/src/ptp08/`, rename the root to `GithubEp08`, scope `tsconfig.json`. Replace the ep07 beats with placeholders: `beats/HA.tsx`, `HB.tsx`, `HC.tsx`, `BodyA.tsx`, `BodyB.tsx`, `BodyC.tsx`, each rendering the kit `Ground` + the shot id and its spoken words (`Placeholder.tsx`). Do not copy ep07's beat folders. Keep the `timing.ts` API unchanged (`useShot`, `useWords`, `useGroupShots`, `useCurrentShot`, `useGlobalFrame`, `useVariant`, `useTiming`, `shotSpan`, `spanProgress`, `isYT`, `hookOf`, `bodyOf`, `Letter`); `groupEdges` may return no breaks.
2. `E/tools/make_ep08_timeline.py` from `make_ep07_timeline.py`: storyboard path, 18 variants, hold ids, CTA detection, `VO_PREFIX`, output `C/src/ptp08/timeline.ts` / `.json`. `--provisional` builds all 18 from the storyboard ranges (combos joined as above). Real timing from `E/timing/words_<variant>.json` (same shape as ep07: `{"text","words":[{"w","s","e"}],"hook_end","body_start","duration"}`) for every variant that has one (VOICE-ASSEMBLE writes all 18). Keep AUTO_LEAD, SPLIT (parts on word starts), MERGE, the 45-frame cap, the number+unit split penalty and every warning. Keep `--variants`, `--out-dir`, `--joined`.
3. Render scripts in `E/dispatch/` from ep07 (same lock, orphan handling, concurrency 1, temp file + exit-code check): `_ptp-lib.sh` (E, ENTRY `src/ptp08/entry.tsx`, COMP `GithubEp08`, the 18 variants), `ptp-stills.sh`, `ptp-preview.sh`, `ptp-render.sh`, `ptp-safe-veil.sh`, `run-silent-finals.sh`, `scan_empty_frames.py`, `scan_pad_edges.py`.
4. Generate the provisional timeline for all 18. Fix every "over 45" warning by leads or splits, never by ignoring it. List every split in your report (builders need the part ids), for the three home variants and note where a combo's body parts differ.
5. Verify: `cd C && npx tsc --noEmit -p src/ptp08/tsconfig.json`, then 3 stills through `ptp-stills.sh` (A f 300, B f 100, CB f 1500), one at a time.
