## 1. Layout rules for the whole group

- One kit `Camera` (`box="body"`, `blur={false}` so text never smears) for A01a-A14b, the shared CTA with its own Camera after an 8-frame blurred crossing (`crossBreak.tsx`) in the pause after "for you.". Starts and ends at identity.
- Captions: `KineticCaption` in the hud, real spoken words, scale 1.6 (connectors 58, bold italic 92, black bar 63 on screen; text-only beat 120). One block per thought; a block is gone (3-frame fade) before the next appears; a word never appears before it is spoken. Default band: top, hud y 240-540 (screen 292-562), visuals below in world y 580-1300 (screen 600-1248). Scenes that need the top (the GitHub slab) keep the band and move the world with the camera instead.
- Shared looks: commit cards = the kit `CommitStrip` with one commit each (`speed 0`, the kit's 340 x 128 card), wire = `WirePath` 7 px + `WireNode` r 15, word chips = `Shared/wordChip.tsx`, GitHub slab = local `BodyA/slab.tsx` (charcoal, 180 px wide, white `github-white.svg`, 'github' under it; the ep04 heavy-block treatment), terminal = `TerminalCard` white bezel with BB's `BodyB/terminalPrompt.tsx` once it exists (a local stand-in with the same look until then).
- Numbers on screen: only `v1`. Commit hashes are generic 7-hex mono strings (a1f3c9e, 4b7d2e0, 9c05f1a, e83b6d4, 27fa0c8, ...), messages plain ('save progress', 'add login page', 'add dark mode', 'fix list', 'new header').
